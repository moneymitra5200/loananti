🔬 Live Resource Audit — MoneyMitra

Monitors your Hostinger server in real-time. Open this file locally while the site is running.

📖 How to Use — Read First

  1. Deploy the latest code to Hostinger (git pull + npm run build + restart server)
  2. Enter your Hostinger site URL below — example: https://moneymitra.com/api/system/diagnostics?secret=diag-secret-2024
  3. Click Start Monitoring — this page auto-refreshes every 5 seconds
  4. Open your site in another tab and browse normally — login as customer, admin, cashier etc.
  5. Watch the API Call Tracker table below — it shows which endpoints are hit most and how slow they are
  6. The Resource Score column tells you which API is eating the most server CPU/DB
  7. When done, click Stop. You can also click Reset Stats to get a clean reading after a specific action
